Problem 1 (15 pts)

  1. (10 pts) State whether each of following sets is a vector space and provide a brief explanation. If it is, state the dimension of the space and provide an appropriate basis.

    1. \(\cpr{\pr{x_{1}, x_{2}, 2} ~|~ x_{1}, x_{2} \in \mbb{R}}\)
    2. \(\cpr{\pr{x_{1}, 0, x_{3}} ~|~ x_{1}, x_{3} \in \mbb{R}}\)
    3. \(\cpr{a_{0} + a_{1} x_{1} + a_{2} x_{2}^{2} + a_{3} x_{3}^{3} ~|~ a_{0}, a_{1}, a_{2}, a_{3} \in \mbb{R}}\)
    4. \(\mbb{C}\) (the set of complex numbers) over the real numbers (the scalars can only be real numbers)
    5. The set of \(2 \times 2\) matrices \(\mc{M}^{2 \times 2}\) over real numbers (each matrix element is a real number and scalars are real numbers) where the scalar multiplication operation is defined by element wise scalar multiplication and the addition operation is defined by matrix multiplication.

  2. (5 pts) Let \(T : \mbb{R}^{3} \rightarrow \mbb{R}^{2}\) be defined by: \[ T(x_{1}, x_{2}, x_{3}) = \pr{2 x_{1} - 7 x_{2} + x_{3} + b, 5 x_{1} + c \, x_{1} x_{3}} \] where \(b, c \in \mbb{R}\). Show that \(T\) is only linear if \(b = 0, c = 0\).

Problem 2 (20 pts)

  1. (6 pts) Determine if the following expressions are correct or not according to ESC. If it is correct, please specify the free and dummy indices.

    1. (2 pts) \(a_{i} b_{i} x_{i}\)
    2. (2 pts) \(A_{i} B_{ij} C_{k}\)
    3. (2 pts) \(P_{\alpha \beta} Q_{\gamma} R_{\beta \sigma}\)

  2. (14 pts) Write down the full form of the following expressions. The index \(i,j = 1,2,3\)

    1. (2 pts) \(a_{ii}\)
    2. (2 pts) \(a_{mn}\pr{x_{m} + y_{n}}\)
    3. (2 pts) \(a_{ij} x_{i} y_{j}\)
    4. (3 pts) \(a_{i} = \dfrac{\partial v_{i}}{\partial t} + v_{j}\dfrac{\partial v_{i}}{\partial x_{j}}\)
    5. (5 pts) Let \(\bs{x} = x_{i} \bs{e}_{i}\), where \(\pr{\bs{e}_{i}}_{i\in(1,2,3)}\) is an orthonormal basis for \(\mbb{E}^3\). What is the matrix representation of \(\dfrac{\partial x_{i}}{\partial x_{j}}\)? How is it related to \(\sqpr{\delta_{ij}}\)?

Problem 3 (15 pts)

Let \(\bs{S}\) be a tensor and \(\bs{a}\) be a vector. The matrix representation of \(\bs{S}\) and \(\bs{a}\) are written as \(\bsf{S} = \sqpr{S_{ij}}\) and \(\bsf{a} = \sqpr{a_{i}}\), where \(i,j = 1,2,3\). The 9 terms \(S_{ij}\) are the components of \(\bs{S}\) and the 3 terms \(a_{i}\) are the components of \(\bs{a}\).

Consider the case where \[ \sqpr{S_{ij}} = \begin{bmatrix} 1 & 0 & 2 \\ 0 & 1 & 2 \\ 3 & 0 & 3 \end{bmatrix} ~, ~~~~~ \sqpr{a_{i}} = \begin{bmatrix} 1 \\ 2 \\ 3 \end{bmatrix} \]

and compute

  1. (2 pts) \(S_{ii}\)
  2. (2 pts) \(S_{ij}S_{ij}\)
  3. (2 pts) \(S_{ij}S_{ji}\)
  4. (2 pts) \(S_{pq}S_{qp}\)
  5. (1 pts) \(a_{i} a_{i}\)
  6. (3 pts) \(S_{im} a_{i} a_{m}\)
  7. (3 pts) \(S_{im} a_{m} a_{i}\)

Problem 4 (15 pts)

Let \(\bs{a}=a_i\bs{e}_i\) and \(\bs{b}=b_i\bs{e}_i\) belong to the Euclidean vector space \(\mbb{E}^3\). The set \((\bs{e}_i)_{i\in (1,2,3)}\) is an orthonormal basis for \(\mbb{E}^3\). That is \(\inpd{\bs{e}_i}{\bs{e}_j}= \delta_{ij}\).

  1. (5 pts) The norm of the vector \(\bs{a}\), written as \(\norm{\bs{a}}\), is \(\inpd{\bs{a}}{\bs{a}}^{1/2}\). Write the norm using the components of \(\bs{a}\) and ESC.
  2. (5 pts) The unit vector \(\hat{\bs{a}}\) corresponding to a vector \(\bs{a}\) is defined as \[ \hat{\bs{a}}=\bs{a}/\norm{\bs{a}}. \] Express \(\hat{\bs{a}}\) using indicial ESC.
  3. (5 pts) Express \(\inpd{\bs{a}}{\bs{b}}\) using ESC.

Problem 5 (20 pts)

  1. (4 pts) Read about the permutation symbol \(\epsilon_{ijk}\) and the vector cross product from [LRK, 2.4] (Lai, Rubin, and Krempl, section 2.4, handout on canvas). Using index notation show that for arbitrary vectors \(\bsf{u},\bsf{v},\) and \(\bsf{w}\) in \(\mbb{R}^{3}\): \[ (\bsf{u}\times\bsf{v})\cdot\bsf{w}+(\bsf{w}\times\bsf{v})\cdot\bsf{u}=\bsf{0}, \] where we are using a short hand for the inner product and writing \(\inpd{\bsf{w}\times\bsf{v}}{\bsf{u}}\) as \((\bsf{w}\times\bsf{v})\cdot\bsf{u}\).

  2. (8 pts) Let \(\det (\bsf{A})\) denote the determinant of the \(3\times3\) matrix \(\bsf{A}\). Show that \[ \det(\bsf{A})=\epsilon_{ijk}A_{i1}A_{j2}A_{k3} \]

  3. (8 pts) Use the identity \(\epsilon_{ijm}\epsilon_{klm}=\delta_{ik}\delta_{jl}-\delta_{il}\delta_{jk}\) to show that \[ \bsf{a}\times (\bsf{b} \times \bsf{c})= (\bsf{a}\cdot \bsf{c})\bsf{b}-(\bsf{a}\cdot \bsf{b})\bsf{c}, \] where \(\bsf{a}\), \(\bsf{b}\), and \(\bsf{c}\in \mbb{R}^3\).

Problem 6 (20 pts)

Read the handout on Fung’s definition of a continuum (you can find this on canvas). This is the definition we will be adopting in class. Specifically, read sections 1.4, 1.5, and 1.7 in the handout.

State True or False

  1. (3 pts) In the classical definition of the continuum the continuum particle \(P\) needs to belong to the set \(\cap_{i=0}^{\infty} \mathscr{V}_i\)

  2. (3 pts) In Fung’s definition of a continuum the continuum particle \(P\) does not need to belong to the set \(\cap_{i=0}^{\infty} \mathscr{V}_i\)

  3. (3 pts) In Fung’s definition of a continuum \[ \lim_{n \to \infty }V_n=0 \]

  4. (3 pts) For any given real continuum, there is a unique abstract copy.

  5. (2 pts) The abstract copy of a real continuum cannot depend on the experimental length scales over which the continuum is being studied

  6. (2 pts) The abstract copy of the continuum cannot depend on the experimental times scales over which the continuum is being studied

  7. (2 pts) An advantage of the abstract copy is that we can do calculus on it exactly

  8. (2 pts) The results of the abstract copy are to be interpreted as an approximation to the experimental measurements on the real continuum
